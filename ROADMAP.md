# Roadmap

## Now

- [ ] **Monodromy Delay / real loop** — feedback delay with Time, Feedback (g < 1), Damping and Mix, and a ±g polarity twist, so the r = −1 octave-down case is playable on day one.

## Next

- [ ] **Monodromy Delay / complex loop** — Hilbert pair into a complex delay buffer, fixed twists e^(i2π/m) with detents on the Twist control, real-part output; measure the Hilbert group delay against the closed-form comb peaks.
- [ ] **Monodromy Delay / rotation and chaos** — continuous twist rotation for barber-pole motion, and a Chaos mode driving the twist from the sine circle map (Ω, K) with |r| = 1.

## Someday

- [ ] **Monodromy Delay / UI polish** — winding-number readout, delay-embedding orbit scope, presets, and a note-tracking Time mode.
